# Postman_CRUD-User-Account
Automation Postman About CRUD for Creating New User

Simple Create New Users API - Tutorial About Automation This API allows you to Create New Users.

The API is available at https://reqres.in/

Get List User = https://reqres.in/api/users?page=1
Get Single User = https://reqres.in/api/users/5
Get User Not Found = https://reqres.in/api/users/23
Create User = https://reqres.in/api/users
Update (PUT) = https://reqres.in/api/users/1
Update (PATCH) = https://reqres.in/api/users/1
Delete = https://reqres.in/api/users/2
Delayed Get List User = https://reqres.in/api/users?delay=2
